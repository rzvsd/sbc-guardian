FSU is an open-source Chrome extension designed for the **EA Sports FC Ultimate Team (FUT) Web App**. It seamlessly injects advanced Squad Building Challenge (SBC) solvers, real-time market prices, player metadata, evolution previews, duplicate item management, and quality-of-life shortcuts directly into the FUT Web App interface.

## ⚡ Features Matrix

| Category | Key Features |
| :--- | :--- |
| **SBC Solver & Assistant** | Quick auto-fill, requirement parsing, squad rating optimizer, unassigned duplicate card handling, and one-click challenge shortcuts. |

## 🚀 Quick Start & Installation

### Option 1: Install Pre-built Extension (Recommended)

1. Go to [Latest Releases](https://github.com/color8892/fsu-fut-enhancer/releases/latest) and download `fsu-fut-enhancer-<version>.zip`.
2. Extract the ZIP file into a dedicated local directory. *(Do not delete or move this folder after installation).*
3. Open Google Chrome (or any Chromium browser) and navigate to `chrome://extensions`.
4. Enable **Developer mode** using the toggle switch in the top-right corner.
5. Click **Load unpacked** and select the extracted directory containing `manifest.json`.
6. Open or refresh the [EA FC FUT Web App](https://www.ea.com/ea-sports-fc/ultimate-team/web-app/).

> [!IMPORTANT]
> Whenever you update or reload the extension, press **F5** on any open FUT Web App tabs to refresh the runtime context.

---

### Option 2: Build from Source

Requires **Node.js 22+** and **npm**:

```bash
# Clone repository
git clone https://github.com/color8892/fsu-fut-enhancer.git
cd fsu-fut-enhancer/extension

# Install dependencies & run build validation
npm ci
npx playwright install chromium
npm run test:ci

# Build userscript & extension output
npm run build
```

After building, load the `extension/` directory into Chrome via `chrome://extensions` -> **Load unpacked**.

## 🛠️ Development & Architecture

Main source code is located in `extension/src/fsu/`. The bundled runtime script `extension/src/userscript.js` is generated by esbuild and should not be manually edited.

```bash
cd extension
npm run lint          # Run ESLint check
npm run typecheck     # Progressive JSDoc & TypeScript strict checking
npm run test:all      # Execute build + typecheck + unit test suite
npm run test:browser  # Playwright MV3 browser smoke tests
npm run test:ci       # Complete CI verification gate
npm run package       # Package release ZIP into dist/
```

### EA Bundle Compatibility Check

To verify compatibility with newly deployed EA Web App JavaScript bundles:

```bash
npm run check:ea-bundle -- --bundles <path-to-local-ea-bundles>
```

> [!CAUTION]
> **Privacy & Security**: Never commit account cookies, session tokens (`X-UT-SID`), HAR dumps, or personal user data to git repositories.
